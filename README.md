
# MediaPlayer VST

[English](README_EN.md)

MediaPlayer VSTは、DAW／VSTホスト内で音声ファイルと動画ファイルを再生するWindows用VST3プラグインです。音声はプラグインのStereo Outputからホストへ送り、動画はサイズ変更可能な独立ウィンドウへ表示します。

## 主な機能

- 音声・動画ファイルの再生、一時停止、停止、シーク
- 音声・動画共通のプレイリスト
- 前の項目／次の項目への移動と、再生終了時の自動次項目送り
- プレイヤー、プレイリスト、動画ウィンドウへのドラッグ＆ドロップ
- ホイールによる音量調整と音量表示
- アスペクト比を維持した動画ウィンドウのサイズ変更
- 動画ウィンドウの移動、全画面表示、シーク操作
- プレイリスト、再生位置、音量、ウィンドウ配置などをVST3状態として保存

本プラグインが外部へ出力するのは音声のみです。動画は独立ウィンドウに表示されますが、映像信号をDAW／VSTホストや配信ソフトへ直接出力する機能はありません。仮想カメラ、NDI、Spoutなどの映像出力にも対応していません。配信で動画を使用する場合は、配信ソフト側で動画ウィンドウを画面またはウィンドウキャプチャーしてください。

再生音声はWindowsの既定デバイスへ直接出力されません。ホスト側でMediaPlayer VSTのStereo Outputを、使用するミキサーや出力先へ接続してください。

設定はレジストリや独自設定ファイルへ保存せず、DAW／VSTホストのプロジェクトまたはプリセット保存に従います。

FFmpegがデコードできる一般的な音声・動画ファイルを扱えます。代表例はWAV、MP3、FLAC、AAC、M4A、OGG、MP4、MKV、MOV、AVI、WebM、WMV、MPEG、M2TSです。実際の再生可否はファイル内のコーデックにも依存します。

## 対応環境

- Windows x64
- VST3対応DAW／VSTホスト

## インストール

ReleaseのZIPを展開し、`MediaPlayer VST.vst3`をVST3プラグインフォルダへコピーしてください。更新時はDAW／VSTホストを終了してから既存ファイルを置き換え、必要に応じてプラグインを再スキャンしてください。

## 使い方

`Open`でメディアファイルを選択するか、プレイヤー本体またはプレイリストへファイルをドラッグ＆ドロップします。動画ファイルは動画ウィンドウへ直接ドラッグ＆ドロップして開くこともできます。

再生ボタンで再生／一時停止を切り替えます。停止すると再生位置は先頭へ戻りますが、メディアは読み込まれた状態を維持します。シークバーは再生中にも操作でき、シーク後も再生を継続します。音量は本体のつまみまたはマウスホイールで調整できます。

`Playlist`を押すとプレイリストの表示／非表示を切り替えます。項目をダブルクリックするとそのファイルを再生します。項目をマウスで掴んでドラッグすると、プレイリスト内で並べ替えられます。選択した項目はDeleteキー、または右クリックメニューの「プレイリストから削除」で個別に外せます。元のメディアファイルは削除されません。`Clear`はプレイリスト全体を消去します。プレイリスト下端をドラッグすると表示領域の高さを変更できます。

動画ウィンドウはシングルクリックで再生／一時停止、ダブルクリックで全画面表示を切り替えます。画面を長押ししてドラッグするとウィンドウを移動できます。マウスホイールでは音量を調整でき、その際は現在の音量が一時表示されます。下端のシークバーは本体と連動します。動画ウィンドウを閉じると一時停止し、本体で再生を再開すると再び表示されます。

プレイリスト、選択中のファイル、再生位置、音量、プレイリスト表示状態、動画ウィンドウの位置とサイズは、DAW／VSTホストのプロジェクト状態として保存されます。

## ビルド

Visual Studio 2022 C++ツールとCMake 3.25以降が必要です。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup_ffmpeg.ps1
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

初回構成時に固定バージョンのVST3 SDKを自動取得します。FFmpegはセットアップスクリプトが固定したWindows x64 LGPL共有版を取得し、SHA-256を検証します。
